## 04. Replace XML-RPC with JSON-RPC API

**As the** ODOO DEMO MAINTAINER \
**I want to** replace all XML-RPC calls with JSON-RPC in `seed_loader.py` \
**In order to** use the modern Odoo API and remove dependency on the deprecated `xmlrpc/2/object` endpoint.

## Description

Odoo 19 still supports XML-RPC (`/xmlrpc/2/common`, `/xmlrpc/2/object`) but the
documentation marks it as deprecated. The recommended replacement is the JSON-RPC
endpoint at `/jsonrpc` (and the future JSON-2 API in Odoo 20). The `db` service
(used for `create_database`, `db_exist`) was removed entirely in Odoo 20.

The current `seed_loader.py` uses a mix of XML-RPC (for model operations) and
JSON-RPC (for database operations). This should be unified.

## Scope

Replace every `xmlrpc.client.ServerProxy` call with equivalent `requests.post`
calls to `POST /jsonrpc`.

### XML-RPC methods used (to replace)

All in `seed_loader.py` | `xmlrpc/2/object`:

| Method | Model | Purpose |
|---|---|---|
| `authenticate` | `xmlrpc/2/common` | Login |
| `execute_kw` | `xmlrpc/2/object` | All CRUD + model methods |
| `search` | `ir.module.module` | Find module |
| `button_immediate_install` | `ir.module.module` | Install module |
| `create` | `account.account` | Create accounts |
| `write` | `res.company` | Update company |
| ... | various | All model operations |

### JSON-RPC equivalent

```python
# XML-RPC (current)
models.execute_kw(db, uid, pass, 'res.partner', 'create', [values])

# JSON-RPC (target)
requests.post(f'{URL}/jsonrpc', json={
    'jsonrpc': '2.0', 'method': 'call',
    'params': {
        'service': 'object',
        'method': 'execute_kw',
        'args': [db, uid, pass, 'res.partner', 'create', [values]]
    },
    'id': 1
})
```

## Impact

- Remove `xmlrpc.client` import
- Replace with `requests` calls (already imported)
- Error handling changes (JSON-RPC returns error objects, not exceptions)
- Existing `requests` usage for `db` methods stays the same

## Out of scope

- Odoo 20 JSON-2 API migration (future)
- Changing the `db` service calls (already JSON-RPC)
