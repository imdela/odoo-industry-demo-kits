## US-Odoo-Accounting: Complete Odoo demo data with invoices

**As the** ODOO DEMO SYSTEM \
**I want to** automatically configure accounting prerequisites and create posted invoices \
**In order to** provide complete demo data that can be pushed to Aion via the invoice-bridge.

## Description

The current `seed_loader.py` creates partners and resources but fails to create invoices because Odoo 19 has no accounting configuration by default (no account types, accounts, journals, or product accounts). The script must be extended to:

1. Set up minimal accounting prerequisites
2. Create posted invoices ready for bridge synchronization

## Current architecture

```
seed_loader.py (XML-RPC)
├── 1. Company configuration
├── 2. Partner import (15 clients from seeds/portage/clients.json)
├── 3. Resource import (40 devs from seeds/portage/developers.json)
└── 4. Transaction history ──✗ FAILS── No sale journal, no accounts
```

## Required changes

### 1. Add accounting setup step to `seed_loader.py`

Insert a new step between company config and partner import (or just before invoice generation):

**Step 1.5 — Accounting bootstrap**

Create via XML-RPC:

> **Odoo 19 compatibility**: `account.account.type` model was removed. The `account_type` field on `account.account` is now a **selection string**, not a many2one. Use direct selection values.

- **Accounts** (`account.account`) with `account_type` selection:
  - `income_account` — code "700000", name "Sales Revenue", account_type = "income"
  - `receivable_account` — code "411000", name "Trade Receivables", account_type = "asset_receivable"
  - `expense_account` — code "600000", name "Expenses", account_type = "expense"
  - `payable_account` — code "401000", name "Trade Payables", account_type = "liability_payable"

- **Accounts** (`account.account`):
  - `income_account` — code "700000", name "Sales Revenue", type = income_type
  - `receivable_account` — code "411000", name "Trade Receivables", type = receivable_type
  - `expense_account` — code "600000", name "Expenses", type = expense_type
  - `payable_account` — code "401000", name "Trade Payables", type = payable_type

- **Journals** (`account.journal`):
  - `sale_journal` — type "sale", code "INV", name "Customer Invoices", default_account_id = income_account
  - `purchase_journal` — type "purchase", code "PUR", name "Supplier Invoices"
  - `bank_journal` — type "bank", code "BNK", name "Bank"
  - `cash_journal` — type "cash", code "CAS", name "Cash"

- **Company defaults** (`res.company` write on company id 1):
  - `income_account_id` = income_account (valid Odoo 19 field)
  - `expense_account_id` = expense_account (valid Odoo 19 field)
  - Note: `default_sale_journal_id` does NOT exist on `res.company` in Odoo 19

### 2. Create product with income account

Update the product creation in step 4 to include `property_account_income_id`:

```python
product_data = {
    'name': 'Consulting Service',
    'type': 'service',
    'list_price': 500,
    'property_account_income_id': income_account_id,
    'invoice_policy': 'order',
}
```

### 3. Invoice line account

When creating invoice lines, explicitly set the `account_id` field to the income account to avoid the "missing account" error.

### 4. Clean flag behavior

The `--clean` flag in `seed_loader.py` currently removes:
- All invoices (`account.move`)
- All sale orders (`sale.order`)
- All partners with `id > 10`

It does NOT remove:
- Products (kept intentionally)
- Accounts or journals (these should persist across clean/reseed)

After this US, `--clean` should also preserve any accounting configuration (account types, accounts, journals) — only reset transactional data.
